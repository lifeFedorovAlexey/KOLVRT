# Реестр решений и свидетельств

Статус ограничен [первым собственным сценарием](../architecture/first-native-slice.md). Отложенная работа становится обязательной при включении названного потребителя. Условия реализации остаются открытыми до выполнения; проектное решение не доказывает реализацию.

| Идентификатор | Статус                                      | Решение или условие активации                                                                                                                                                                                                                                |
| ------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| OQ-01         | Решено для сценария                         | Изолированная служба EL0; [решение 0008](../architecture-decisions/0008-placement.md). Драйверы прямого доступа к памяти и адаптеры совместимости требуют отдельной нагрузки и анализа угроз                                                                 |
| OQ-02         | Решено для сценария                         | Наблюдатель запускает два статических доверенных образа в отдельных адресных пространствах, выдаёт явные дескрипторы и наблюдает окончательные события задач; без копирования процесса и загрузчика исполняемых файлов                                       |
| OQ-03         | Смоделировано для сценария                  | Один объект и семантическая привязка сохраняются при передаче дескриптора с суженными правами; смена действующей привязки ожидает завершения запросов. Файлы, учётные данные и блокировки между средами требуют моделей при введении                         |
| OQ-04         | Отложено                                    | Идентичность и замена USB необходимы до добавления устройств USB                                                                                                                                                                                             |
| OQ-05         | Решено для сценария                         | Принятые запросы учитываются за принявшей областью до окончательного освобождения, с ограниченными пулами объектов и очередей. Учёт кеша и прямого доступа к памяти предшествует этим возможностям                                                           |
| OQ-06         | Решено для сценария                         | Блокировки объектов и удерживаемые ссылки; получение ссылок под блокировкой объекта, без воскрешения. RCU и эпохи требуют доказанной проблемы конкуренции                                                                                                    |
| OQ-07         | Решено для сценария                         | Равноправный циклический выбор при условии доставки прерываний таймера и ограниченной невытесняемой работы; без обещания жёстких задержек реального времени                                                                                                  |
| OQ-08         | Условие реализации                          | [Контракт платформы](../architecture/platform-contract.md) фиксирует обязанности упорядочивания, MMU, GIC и таймера. До кода платформы проверить последовательности регистров и первичную спецификацию таймера; VirtIO и прямой доступ к памяти вне сценария |
| OQ-09         | Проект зафиксирован                         | Rust, LLVM и конфигурация эмулятора записаны в контракте платформы; перекрёстная компиляция без стандартной библиотеки выполнена. Компоновка и загрузка остаются условиями реализации                                                                        |
| OQ-10         | Решено для сценария                         | Привилегированная паника останавливает систему, без раскрутки стека через прерывания; ошибки ограниченного выделения явные, гибель службы наблюдаема. См. [модель угроз](../architecture/threat-model.md)                                                    |
| OQ-11         | Отложено                                    | Вывод совместимости требует настоящего адаптера и инвентаризации потребителей                                                                                                                                                                                |
| OQ-12         | Отложено                                    | Бюджеты миграции требуют настоящей переносимой нагрузки; для полностью собственного сценария они не выдумываются                                                                                                                                             |
| OQ-13         | Долг исследования                           | Неизвестные исторические версии появления остаются явными. Завершить происхождение до опоры на конкретный интервал версий                                                                                                                                    |
| OQ-14         | Долг исследования                           | Причинное воспроизведение случая 30 не выполнено. Не использовать поиск изменений по неработающему исправлению как доказательство причинности; собственные модели времени жизни имеют независимые инварианты                                                 |
| OQ-15         | Область решена; действие владельца остаётся | Первоначальная цель исполнения — QEMU virt AArch64, а не все платы. До публичного распространения лицензию проекта выбирает владелец                                                                                                                         |

[Итоговое ревью](phase-0-review.md) указывает реально полученные свидетельства. [Вопросы отдельных случаев](case-index.md) и [выводы по другим системам](reference-systems.md) сохраняют ограничения.
