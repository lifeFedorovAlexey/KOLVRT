# Подача issues об оборудовании и совместимости

Document status: CURRENT
Evidence scope: определения форм issues, локальная проверка и проверка реального отображения/заполнения GitHub после входа 2026-10-05; без сбора оборудования и публикации пробных issues.
Current reference: [Исследовательская программа](../../research/compatibility/taxonomy.md)

## Выбор формы

Пять [форм issues](../../../../.github/ISSUE_TEMPLATE/) собирают ограниченные запросы и свидетельства для [программы #44](https://github.com/lifeFedorovAlexey/KOLVRT/issues/44). Ответы допускаются на английском или русском. Пустые issues остаются доступны; метки, исполнители и настройки маршрутизации не добавляются.

| Форма                          | Назначение                                                                        | Безопасный пример области                                                                                              |
| ------------------------------ | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Hardware Bring-up Request      | Конкретная цель загрузки/операции устройства и ограниченный план проверки         | boot_target; QEMU VirtIO block; операция устройства NOT RUN; DMA/IOMMU UNKNOWN                                         |
| Driver Compatibility Research  | Зафиксированные исходники и повторяющиеся семантические зависимости               | Исходник igb Linux v6.12; только лексические наблюдения; поведение с конфигурацией/транзитивными зависимостями UNKNOWN |
| COST-L Candidate               | Повторяющаяся семантика, история, отличие native и вопросы удаления               | Существующий кандидат COST-L-0001; свидетельства о контексте выделения; принятое native-отличие UNKNOWN                |
| Hardware Test Result           | Точный контекст выполненной проверки, результат и ограничения                     | Только сбор на хосте; сборка KOLVRT NOT RUN; нет заявленных гарантий загрузки, устройства или изоляции                 |
| Compatibility Adapter Proposal | Конкретные потребители, ограниченное время жизни, поддержка и native-альтернатива | Предлагаемый модуль; потребители UNKNOWN; расходы UNKNOWN; решение отложено до получения свидетельств                  |

Это примеры областей, а не опубликованные результаты. Имя upstream-драйвера или совпадение в исходнике не доказывает поддержку драйвера KOLVRT. Инвентаризация хоста не является тестом оборудования KOLVRT. QEMU, физическая загрузка и физическая операция устройства имеют отдельные области; PASS относится только к указанным проверенным гарантиям. Указывайте точный коммит/сборку/features/профиль выполненного теста KOLVRT и NOT RUN для предложения или сбора только на хосте.

## Проверка точного публичного содержимого

[Локальный сборщик сведений](host-survey.md) предоставляет сбор разрешённых полей и синтетические проверки для #53. Команда по умолчанию выводит справку; явный сбор ничего не публикует. Отчёт об исследовательской машине не является проверкой загрузочной платформы или физического исполнения KOLVRT.

Публичные названия моделей и идентификаторы производителя/устройства шины описывают устройство без идентификации компьютера. Не публикуйте сырые инвентаризации, неограниченные логи или дампы. Локально удалите секреты, серийные номера, MAC/IP/SSID, имена пользователей и хостов, приватные пути из каждого поля и вложения. Проверьте точный очищенный текст до отправки. Скриншоты и вложения требуют той же проверки. Обязательное подтверждение фиксирует проверку отправителем; оно не очищает данные автоматически и не разрешает дополнительный сбор/публикацию. UNKNOWN с причиной лучше догадки.

## Проверка ссылок COST-L и решений

Выделенные ID имеют формат COST-L-#### с четырьмя цифрами; COST-L-0000 зарезервирован. Сверяйте каждый выделенный ID с [реестром выделения](../../../../research/cost-l/registry.json). Невыделенные предложения используют candidate со ссылкой на issue. Поля формы не выделяют ID, не подтверждают записи и не расширяют полномочия. [Контракт реестра](../architecture/compatibility-debt.md) отдельно проверяет идентичность выделенных записей и семантические связи.

Проверки форм GitHub требуют ответов и подтверждений; эти формы не применяют регулярное выражение к свободному тексту и не проверяют историческую истину. До преобразования заявки в запись рецензенты должны отклонять некорректные, зарезервированные или невыделенные стабильные ссылки, неоднозначные области свидетельств и выдуманные расходы. Исследовательские классификации используют словарь реестра; форма также допускает неустановленную классификацию с причиной. Владелец, native-решение, гарантии IOMMU и измеренные расходы могут быть неизвестны при предложении. Декларации поддержки и выполненные наблюдения остаются разными понятиями.

## Проверка и доступность

YAML использует [синтаксис issue forms](https://docs.github.com/en/communities/using-templates-to-encourage-useful-issues-and-pull-requests/syntax-for-issue-forms) и [схему форм](https://docs.github.com/en/communities/using-templates-to-encourage-useful-issues-and-pull-requests/syntax-for-githubs-form-schema) GitHub. Локальная проверка разбирает все пять форм, проверяет идентификаторы, обязательные поля, уникальность вариантов списков, подтверждения, варианты классификации и ссылки репозитория, а также создаёт пример/предпросмотр каждой формы. Пять форм вошли в ветку по умолчанию в PR #60. Локальные проверки подтверждают структуру, но не реальное отображение GitHub и не семантическую корректность будущих ответов.

2026-10-05 проверка через браузер после входа для [issue #56](https://github.com/lifeFedorovAlexey/KOLVRT/issues/56) охватила реальный выбор и все пять форм. Синтетические черновики проверили редактируемые поля, Markdown-предпросмотры, варианты списков и подтверждения приватности. Пустые заголовки, обязательные текстовые поля и неотмеченные подтверждения вызвали ошибки валидации GitHub; необязательное upstream-поле Hardware Bring-up осталось необязательным. Выбор сохранил Blank issue, метки не добавлялись. Некорректный/зарезервированный/невыделенный текст COST-L остался редактируемым, как и описано; проверка рецензентом по-прежнему обязательна. [Запись проверки](../../../../research/results/issue56-live-forms.json) указывает точные исходники форм и ограничения наблюдения. Пробные issues, инвентаризации, вложения и результаты аппаратных тестов не публиковались. Будущие изменения форм требуют новой проверки; это наблюдение не сертифицирует будущие ответы или версии интерфейса GitHub.
