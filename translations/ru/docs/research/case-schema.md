# Схема случая, версия 1

[case.schema.json](../../../../schemas/research-case.schema.json) использует JSON Schema Draft 2020-12 с закрытой структурой: неизвестные свойства отклоняются. Все объявленные обязательными поля должны присутствовать. Неизвестное происхождение обозначается null с объяснением, а не выдуманной датой или суммой.

[Проверка исследования](../../crates/repository-checks/README.md) на Rust применяет схему с проверкой форматов и дополнительно проверяет уникальность ключей и идентификаторов, имена файлов, первичные источники, ссылки на свидетельства, даты, согласованность решений и совместимости, вопросы для неизвестной истории. Этап 0.1 требует не менее 30 исследовательских случаев; это число результатов исследования не связано с числом законов ядра. Пустые или отсутствующие базы отклоняются.

Решения: NATIVE_FIX, COMPAT_ONLY, HARDWARE_TRANSLATION, ACCEPTED_TRADEOFF, RESEARCH_REQUIRED или NOT_APPLICABLE. Совместимость CONDITIONAL не является обещанием реализации.

Несовместимое изменение схемы требует решения о миграции к версии 2. Сохранять различия между неизвестным, ложным и неприменимым.
