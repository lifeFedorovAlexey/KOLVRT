# Ревью проекта нулевого этапа

Дата: 2026-10-02. Область: проверяемая проектная основа [первого собственного сценария](../architecture/first-native-slice.md). Это самостоятельное ревью, а не независимая сертификация. Первый этап требует отдельного указания; реализации ядра нет.

## Свидетельства приёмки

| Обязательство                                | Результат и граница                                                                                                                                                                                                                     |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Собственная нагрузка и критерий корректности | Две изолированные задачи, наблюдаемая ограниченная служба и явные окончательные исходы; без требований файловой системы, сети и чужого двоичного интерфейса                                                                             |
| Аудит законов                                | [20 действующих законов](../architecture/law-audit.md); три добавления закрывают продвижение, области отказа и жизненный цикл подсистем; количество является результатом аудита, а не квотой                                            |
| Полномочия и двоичный интерфейс запросов     | [Кандидат версии 0](../architecture/native-abi.md), собственные снимки, сужение прав, вывод поколений из обращения, проверенная идентичность ответа                                                                                     |
| Время жизни, ожидание, привязка и запуск     | [Конечные модели](../../../../research/results/native-state-models.json): 535 достижимых состояний и 1 334 перехода, обнаружены шесть намеренно испорченных вариантов                                                                   |
| Размещение                                   | [Принятое решение](../architecture-decisions/0008-placement.md); настоящий обмен через канал, обнаружение отказа дочернего процесса и восстановление, отклонение повреждённого ответа; без утверждений о песочнице и производительности |
| Платформа и доверие                          | [Зафиксированный контракт платформы](../architecture/platform-contract.md), [модель угроз](../architecture/threat-model.md), перекрёстная компиляция кандидата без стандартной библиотеки для AArch64                                   |
| Качество репозитория                         | Автоматическая цепочка форматирования, анализа и тестов, английские исходники с проверенными русскими переводами, схема случаев и проверки ссылок и хешей                                                                               |

Модель обходит каждое достижимое состояние представленных конечных систем переходов без ограничения глубины. Она не представляет слабую модель памяти, оборудование, произвольные размеры очередей и все возможные расписания будущего ядра. Проверка циклического выбора предполагает доставку таймера и ограниченную невытесняемую работу. Изоляция процесса основной системы демонстрирует наблюдение отказа, а не будущую границу привилегий.

## Исправленные замечания ревью

Старая проверка прослеживаемости законов непреднамеренно запрещала добавления; теперь она проверяет обоснованные добавления вместе с объединением. Протокол ответа не проверял идентичность; кандидат теперь кодирует и проверяет весь заголовок ответа и отклоняет испорченный резерв. Выведенный из обращения слот дескриптора мешал использовать другой свободный слот; выделение теперь пропускает исчерпанные поколения и имеет регрессионный тест. Исследовательские программы, данные и справочные документы были смешаны; структура репозитория теперь разделяет их обязанности.

## Закрытие и оставшиеся условия

Проектная основа нулевого этапа завершена, когда зафиксированное дерево проходит команды ниже. Завершение не означает готового проекта каждой будущей подсистемы. [Открытые вопросы](open-questions.md) явно отделяют решения первого сценария от отложенных возможностей и свидетельств реализации. Исторические случаи сохраняют неизвестное происхождение и невоспроизведённые отказы; они служат вспомогательными свидетельствами, а не доказательствами собственного проекта.

До принятия кода ядра проверить настоящий вход исключений, таблицы страниц, безопасное при сбоях копирование пользовательской памяти, последовательности регистров таймера и GIC и многопроцессорное упорядочивание. До заявления о работоспособности первого сценария выполнить проверки изоляции, исчерпания, отмены и завершения на зафиксированной платформе. QEMU и настоящее оборудование не запускались. Лицензию до публичного распространения по-прежнему выбирает владелец проекта.

## Воспроизведение

Запускать с зафиксированным набором инструментов и зависимостями:

```text
npm ci --ignore-scripts
npm run check
cargo check --locked -p native-protocol-model --target aarch64-unknown-none
cargo test --locked --release -p native-state-models -p native-protocol-model
```

При отсутствии цели AArch64 установить её через rustup. Режим проверки сравнивает свидетельства, не переписывая их. Изменения требуют ревью до записи нового результата.
