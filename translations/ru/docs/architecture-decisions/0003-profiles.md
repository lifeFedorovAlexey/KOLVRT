# ADR-0003 — Единая архитектура для профилей исполнения

Document status: CURRENT
Evidence scope: Принятые требования; реализация и проверка имеют отдельные границы доказательств.
Current reference: [Documentation policy](../documentation-policy.md)

Статус: **Принято**. Дата: 2026-10-02.

## Контекст

Отладочные средства меняют временное поведение; выпускные сборки обязаны сохранять безопасность (случаи 10, 18, 30).

## Решение

STAGING использует производственную конфигурацию с ограниченной диагностикой. DEV, STAGING и PROD имеют единый собственный контракт.

## Альтернативы

Отдельное производственное ядро; проверка только отладочной сборки; полная трассировка везде.

## Почему отклонены

Архитектуры расходятся, отладочное временное поведение может скрывать сбои, неограниченная трассировка превышает допустимые затраты.

## Последствия

Матрица проверок охватывает сочетания оптимизации и диагностических средств. PROD с полностью удалённой диагностикой не предоставляет динамических счётчиков.

## Влияние на совместимость

Профиль не выбирает маршрут совместимости.

## Влияние на производительность

Необязательную диагностику можно удалить при компиляции; обязательные проверки сохраняются.

## Влияние на безопасность

PROD исключает внедрение сбоев и эксперименты во время работы, но сохраняет проверку входных данных.

## Проверка

Выполнять семантические проверки во всех профилях и измерять накладные расходы наблюдения.

## Обратимость

Бюджеты и значения по умолчанию могут меняться без изменения семантики интерфейса.
