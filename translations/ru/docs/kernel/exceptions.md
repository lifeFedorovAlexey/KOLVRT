# Вход в исключения и восстановление

Шестнадцать слотов векторов AArch64 направляют синхронные faults, IRQ или fatal paths. Rust выполняется со стеком, выровненным на 16 байт. Входной frame размером 784 байта сохраняет все общие регистры, Q0–Q31, FPCR и FPSR. Закреплённый Rust runtime поддерживает NEON; сохранение только общих регистров повреждало бы прерванный код. Настоящий таймерный тест намеренно перезаписывает SIMD/FP-состояние внутри IRQ и проверяет восстановление.

## Политика faults

PROD не содержит механизма тестового восстановления. Неожиданные исключения маскируют IRQ, останавливают таймер, публикуют ошибку при доступном UART и вызывают PSCI shutdown. DEV дополнительно сообщает ESR, FAR и ELR. Сборки kernel-tests допускают восстановление только по точному зарегистрированному PC probe для BRK, data abort текущего EL или instruction abort. Тесты проверяют класс fault ESR и FAR при настоящей записи в RO, чтении unmapped и выборке инструкции NX.

Векторы устанавливаются до тестов защиты памяти. IRQ не вкладываются в этом milestone. Обнаружение переполнения стека и отдельные exception stacks для CPU требуют дальнейшего проектирования до конкурентного выполнения. [Unsafe-инварианты](unsafe.md) описывают предположения ассемблера; [границы SMP](smp.md) определяют область конкурентности.
