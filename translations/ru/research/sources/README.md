# Реестр источников

Дата исследования: **2026-10-02**. [Источники Linux](../../../../research/sources/case-sources.json) содержат адреса, репозитории, подтверждённые коммиты, метки и даты, указатели и ограничения. Случаи включают те же сведения с обозначениями подсистем. [Другие источники](../../../../research/sources/other-sources.json) охватывают остальные системы и основания.

Предпочитать исходный код и коммиты, официальную документацию, отчёты об ошибках, средства воспроизведения, записи CVE и обсуждения разработчиков вторичному анализу. Linux man-pages — первичная документация пользовательского интерфейса. Отчёт обнаружившего Dirty Pipe исследователя сопоставлен с исправляющим коммитом.

Первоначальное исследование читало веб-страницы. Оно не клонировало весь Linux, не выполняло локальный анализ истории или двоичный поиск, не собирало исторические ядра и не воспроизводило поведение при исполнении. Полные копии чужих страниц здесь не хранятся. Обновляемая документация может меняться; закрепление неизменяемых редакций и контрольных сумм получения остаётся работой этапа 0.2.

Не угадывать отсутствующие коммиты или даты. Перед получением редакции разрешать записанные префиксы коммитов в полные суммы. ARM64 Kconfig прочитан на v6.12. Man-pages 6.19 — версия документации, а не утверждение о ядре Linux 6.19.

## Ограничения доступа

- Доступ оболочки к raw.githubusercontent.com был заблокирован; исследование продолжалось через веб-инструмент.
- Сервер книги Redox вернул 403; прочитано официальное зеркало `our-goals.md` на GitHub.
- Руководство FreeBSD первоначально было недоступно; были доступны официальная архитектурная статья и отчёт второго квартала 2023 года. Старая статья для i386 не описывает каждый нынешний перенос.
- Обсуждение LKML/lore для случая 30 было недоступно. Свидетельства панели отчётов, средства воспроизведения и исправления сохранены; намерения сверх сообщения коммита не утверждаются.
- Кандидаты удаления set_fs и уязвимости futex PI остаются в плане, поскольку первичные коммиты не удалось достаточно прочитать.

Для разрешения спорных утверждений повторно открыть указатель и закреплённую историю. Недоступность создаёт открытый вопрос, а не разрешение выдумать источник. Проверка не делает HTTP-запросов и не обещает будущую доступность ссылок.
