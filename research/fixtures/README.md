# Platform fixture provenance

virt-10.1.dtb is a binary device tree generated by QEMU 10.1.0, not another kernel's source. It is used by host parser tests; real kernel runs read QEMU's boot-supplied DTB.

## Regeneration

```text
qemu-system-aarch64 -machine virt-10.1,gic-version=3,virtualization=on,its=off,dtb-randomness=off,dumpdtb=target/kernel/virt.dtb -cpu cortex-a57 -accel tcg -smp 2 -m 256M -display none -monitor none -nic none
```

Copy the generated file only after comparing platform descriptors and reviewing any change. The test rejects every strict truncation of the supplied fixture, malformed offsets, version and alignment. This establishes parser rejection behavior for those inputs, not universal boot-firmware safety.
