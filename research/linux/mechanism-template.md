# Linux mechanism research template

Research facts, historical-causality hypotheses, engineering comparisons and accepted KOLVRT decisions are distinct. Do not call a model explanation a maintainer fact. Missing evidence is UNKNOWN. Prefer versioned docs.kernel.org, pinned source, Git history, LKML/subsystem discussions and primary maintainer documentation. Record version, commit/tag, architecture/configuration when relevant, source path/locator and review date. An external mechanism is not a KOLVRT requirement.

Domains grow only when needed: process, scheduler, memory, locking, rcu, irq, workqueue, device, pci, usb, dma, iommu, vfs, block, network, power, firmware, security and abi. Stable addresses use `linux.<domain>.<mechanism>`.
